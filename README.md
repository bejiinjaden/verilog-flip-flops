Verilog Flip-Flops

A collection of basic flip-flop implementations in Verilog, along with their testbenches. These designs focus on fundamental sequential logic concepts and are written to be simple, clear, and easy to understand.

This repository is part of my learning journey in digital design and VLSI, aiming to build strong fundamentals through practical implementation and simulation.

**Included Designs**
-SR Flip-Flop
-JK Flip-Flop
-Master-Slave Flip-Flop

**Features**
-Synthesizable Verilog code
-Clean and minimal design
-Testbenches for verification
-Compatible with standard simulators (ModelSim, Vivado)

**Usage**
-Compile design and testbench files
-Run simulation
-Observe outputs via waveform or console
